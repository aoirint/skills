# development-environment-update-workflow

## Overview

Inventory and update developer-machine toolchains on Windows 11 25H2 or later,
Ubuntu 24.04 or later on WSL2, and native Ubuntu 24.04 or later.
Compare retaining, updating, or migrating installed tools against actual project
use, with scoped changes and recovery checks.
